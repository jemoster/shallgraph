This is test data and examples for the project. No requirements under this hierarchy are product requirements for shallgraph itself.

- **basic** – General sample project with requirements in multiple categories. `shallgraph.yaml` defines custom tags (`priority`, `component`, and `concern`) and each requirement file sets them. `system/streaming.req.yml` stores two requirements in one file; the filename does not match either id.
- **rust** – Small Rust crate (`tempconv`) that tags implementation and tests so the HTML report lists implementation and verification links.
